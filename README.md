# Security Analyst Portfolio — Isaac Osei Mensah

Training portfolio: lab investigations and scenario work products, built to show how I work, not just what I have studied. Everything here comes from simulated lab data and fictional scenarios. No production data, no real patient information, nothing from an employer's systems.

## Contents

1. **SOC Case File — Brute-Force Login Investigation** (`01-soc-case-file-brute-force.md`)
   A full alert-to-verdict investigation of a Windows brute-force attack in a lab dataset: event log analysis (4625 → 4624 pattern), IOCs, MITRE ATT&CK mapping, escalation wording, and the ticket note.

2. **GRC Work Product — Risk Register and Vendor Review** (`02-grc-risk-register-vendor-review.md`)
   A five-risk register for a fictional community clinic (HIPAA Security Rule mapped to NIST CSF 2.0), plus a one-page review of a vendor's SOC 2 Type II report with a decision and conditions.

3. **Detection Rule — Successful Logon After Repeated Failures** (`03-sigma-detection-rule.md`)
   A Sigma rule with correlation logic, MITRE ATT&CK tags, false-positive notes, test results against sample logs, and equivalent Splunk SPL and Microsoft Sentinel KQL queries.

4. **Coursework Archive — Certificate Program Activity Documents** (`04-coursework-archive.md`)
   An index of the hands-on activity documents from my Google Cybersecurity Certificate coursework (Botium Toys security audit, incident reports, risk register, PASTA threat modelling, SQL/Linux/Python activities) and GRC Mastery vulnerability scan reporting, stored in my Google Drive.

5. **Security Audit Project — Botium Toys** (`05-botium-toys-security-audit.md`)
   The full Botium Toys audit from my Google Cybersecurity Certificate coursework, read from the original Drive documents: scope and goals, the risk assessment (score 8/10), the prioritised controls assessment, the GDPR/PCI DSS compliance checklist, and the signed stakeholder memorandum with its critical findings and recommendations.

6. **Incident Response Coursework — Network Traffic Analysis, Handler's Journal, Phishing Playbook** (`06-incident-response-coursework.md`)
   A completed incident report tracing a website outage through DNS/ICMP traffic in tcpdump to a "UDP port 53 unreachable" finding; the one completed incident handler's journal entry (a ransomware scenario documented with the 5 W's); and the programme's phishing playbook workflow, described as course material.

7. **Risk, Vulnerability, and Threat-Modelling Coursework** (`07-risk-vulnerability-threat-modelling.md`)
   A security risk assessment report's hardening recommendations (MFA, firewall rules, IPS, SIEM log analysis); the bank-scenario risk register exercise (scores not completed, stated plainly); a completed NIST SP 800-30-guided vulnerability assessment of a publicly accessible database server; and a full seven-stage PASTA threat model of a sneaker company's app.
